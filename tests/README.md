# tests/

运行：`.venv/bin/python -m pytest`（配置见 `pyproject.toml`）。

| 位置 | 内容 | 何时出现 |
|---|---|---|
| `test_layout.py` | 框架结构冒烟测试：功能区可导入、有说明、已在 architecture.md 登记；版本号与 pyproject 一致 | 已有 |
| `<area>/test_*.py` | 各功能区的单元测试，使用小规模合成数据 | 随对应功能区一起实现 |
| `leakage/` | 时间边界与泄漏测试 | M3 起必须有 |
| `contract/` | 基于真实数据的合同测试；数据缺失时 `pytest.skip`，不算失败 | M1 起 |

## 必须覆盖的核心风险（交接文档 §11）

1. 手算的指标值和 mask 计数；
2. grid 的 0 值被正确排除；
3. 各序列有效数量不同时，整体平均是否正确；
4. 监督样本的目标跨越训练边界时被拒绝；
5. 修改未来的真实值，不会改变已构造的特征和预测；
6. 第 289 步没有偷看真实值；
7. 输出与 test.csv 精确匹配；
8. 失败的运行不会被标为成功。

只写与这些核心风险相关的测试，不为无关的格式变化编造大量测试。测试中不得读取 sample 文件的数值（ADR-0005）。
