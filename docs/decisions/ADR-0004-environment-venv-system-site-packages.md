# ADR-0004 项目 venv 复用镜像包

- 状态：accepted
- 日期：2026-10-26
- 提出与执行：cursor/claude-opus-5.5（T-20261026-01）
- 学生复核：pending

## 背景

学校镜像的系统 Python 是 3.12.3，自带 NVIDIA 构建的 torch 2.12（CUDA 13.2）、numpy 2.1.0、pandas 3.0.2 等包，并通过 `PIP_CONSTRAINT` 固定了一批版本。但镜像里没有 pytest 和 ruff。

旧 `requirements.txt` 声明了 scikit-learn、seaborn、pytest 等包，实际上都没有安装，与真实环境不一致。

交接文档要求：不修改系统 Python 和 CUDA；复用已经可用的环境；只锁定真实验证过的依赖；基础阶段只装最少的依赖。

## 决策

1. 在持久盘上创建项目 venv：`python3 -m venv --system-site-packages .venv`。镜像里的 numpy、pandas、torch 直接复用，新增的包只装进 `.venv`。
2. 依赖的唯一来源是 `pyproject.toml`：
   - 运行依赖：numpy、pandas、PyYAML、matplotlib；
   - `[dev]` 依赖：pytest、ruff。
   - 旧的 `requirements.txt` 删除。
3. `requirements.lock` 记录 2026-10-26 实测的版本：镜像提供的包和 `.venv` 新装的包分开列出。
4. scikit-learn、statsmodels、深度学习框架等，由第一个真正需要它们的任务再加入，并说明原因。

## 后果

- 如果换了镜像或 Python 版本，`.venv` 需要按 `docs/runbooks/environment.md` §6 重建。（T-20261026-02 扩写该手册后，章节号由 §3 变为 §6。）
- 拿到的 pandas 是 3.x，代码要按 Copy-on-Write 语义编写（`docs/standards/coding.md`）。
