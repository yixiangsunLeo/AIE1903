# notebooks/

Notebook 只用于探索想法和展示结果。稳定的数据处理、特征、模型和评估逻辑，必须放进 `src/aie1903/` 对应的功能区，notebook 只负责调用和呈现。

- **命名**：`NN_<topic>.ipynb`，例如 `01_eda_cell_217.ipynb`。
- **内核**：使用项目的 `.venv`。
- **提交前清空输出**，原因有两个：避免暴露受限信息（课程要求），也让 diff 保持干净。
- 不要依赖未记录的执行顺序或全局变量；不要在 notebook 里保存密码或令牌。
- 同样受泄漏规则约束：只用训练数据；不读取 sample 文件的数值；一个 notebook 只分析一个数据集，除非任务卡明确声明了 ADR-0005 中的例外。
